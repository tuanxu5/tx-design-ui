# TX Design UI

A modern React UI component library with beautiful, customizable components.

## Features

- 🎨 **Modern Design** - Clean and professional design system
- 🎯 **Easy to Use** - Simple and intuitive API
- 🔧 **Customizable** - Extensive theming and styling options
- 📦 **Lightweight** - Optimized bundle size
- 🌈 **Rich Components** - Growing collection of UI components
- 🎭 **TypeScript Ready** - Full TypeScript support
- 🌓 **Theme System** - Centralized color management

## Components

TX Design UI provides a rich set of components for building modern web applications:

### Data Entry

- **[Button](/docs/component/data-entry/button)** - Interactive buttons with multiple styles and states
- **[Input](/docs/component/data-entry/input)** - Text input with various features and validations
- **[Checkbox](/docs/component/data-entry/checkbox)** - Select single or multiple values from options
- **[Radio](/docs/component/data-entry/radio)** - Select a single option from a set
- **[Select](/docs/component/data-entry/select)** - Dropdown selection from options
- **[InputNumber](/docs/component/data-entry/input-number)** - Numeric input with controls
- **[DatePicker](/docs/component/data-entry/date-picker)** - Date and time selection
- **[ColorPicker](/docs/component/data-entry/color-picker)** - Color selection with presets
- **[Switch](/docs/component/data-entry/switch)** - Toggle switch component
- **[Slider](/docs/component/data-entry/slider)** - Slider for value selection
- **[Upload](/docs/component/data-entry/upload)** - File upload with drag and drop
- **[Form](/docs/component/data-entry/form)** - Form with validation

### Data Display

- **[Avatar](/docs/component/data-display/avatar)** - Display user profile pictures or initials
- **[Badge](/docs/component/data-display/badge)** - Badge for counts and status
- **[Table](/docs/component/data-display/table)** - Display rows of structured data
- **[Tag](/docs/component/data-display/tag)** - Labels to categorize or organize items
- **[Timeline](/docs/component/data-display/timeline)** - Vertical timeline display
- **[Carousel](/docs/component/data-display/carousel)** - Carousel/slider for images and content

### Feedback

- **[Modal](/docs/component/feedback/modal)** - Display content in a layer above the app
- **[Drawer](/docs/component/feedback/drawer)** - Panel that slides in from the edge
- **[Notification](/docs/component/feedback/notification)** - Display notification messages globally
- **[Popconfirm](/docs/component/feedback/popconfirm)** - Simple confirmation dialog
- **[Tooltip](/docs/component/feedback/tooltip)** - Text popup tip on hover
- **[Loading](/docs/component/feedback/loading)** - Spinner for loading states
- **[Message](/docs/component/feedback/message)** - Global message feedback
- **[Progress](/docs/component/feedback/progress)** - Progress indicator

### Navigation

- **[Tabs](/docs/component/navigation/tabs)** - Tab navigation interface
- **[Steps](/docs/component/navigation/steps)** - Step-by-step wizard navigation
- **[Pagination](/docs/component/navigation/pagination)** - Pagination controls for data
- **[Menu](/docs/component/navigation/menu)** - Navigation menu with sub-menus
- **[Dropdown](/docs/component/navigation/dropdown)** - Dropdown menu with actions
- **[Breadcrumb](/docs/component/navigation/breadcrumb)** - Breadcrumb navigation trail
- **[Anchor](/docs/component/navigation/anchor)** - Anchor links for page sections

### Foundation

- **[Icons](/docs/component/foundation/icons)** - SVG icon library with usage guidelines

## Design Principles

### Consistency

TX Design UI follows consistent design patterns across all components, ensuring a cohesive user experience.

### Accessibility

All components are built with accessibility in mind, following WAI-ARIA standards and best practices.

### Performance

Components are optimized for performance with minimal re-renders and efficient DOM updates.

### Customization

Every component supports extensive customization through props and theming system.

## Browser Support

TX Design UI supports all modern browsers:

- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)
