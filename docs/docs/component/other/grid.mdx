# Grid

CSS Grid layout component.

## When To Use

- Create responsive layouts
- Organize content in grids
- Display card collections

## Basic Usage

<Tabs>
  <TabItem value="preview" label="Preview" default>

    ```jsx
    import { TxGrid, TxGridItem } from "tx-design-ui";

    <TxGrid columns="repeat(3, 1fr)" gap="16px">
      <TxGridItem>Item 1</TxGridItem>
      <TxGridItem>Item 2</TxGridItem>

    </TxGrid>
    ```

  </TabItem>

## API

| Property | Type     | Default | Description  |
| -------- | -------- | ------- | ------------ |
| columns  | `string` | -       | Grid columns |
| gap      | `string` | `16px`  | Grid gap     |
| children | `node`   | -       | Grid items   |
