# QR Code

Generate and display QR codes.

## When To Use

- Share links quickly
- Mobile scanning
- Contact information

## Basic Usage

<Tabs>
  <TabItem value="preview" label="Preview" default>
    <iframe
      src="https://storybook-tx-design.pages.dev/iframe.html?args=&id=tx-design-ui-other-txqrcode--basic&viewMode=story"

    />
  </TabItem>
  <TabItem value="code" label="Code">
    ```jsx
    import { TxQrcode } from "tx-design-ui";

    <TxQrcode value="https://www.example.com" size={200} />
    ```

  </TabItem>
</Tabs>

## API

| Property | Type     | Default | Description     |
| -------- | -------- | ------- | --------------- |
| value    | `string` | -       | QR code content |
| size     | `number` | `200`   | QR code size    |
