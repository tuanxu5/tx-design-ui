# Map

Embed interactive maps using Google Maps.

## When To Use

- Display location information
- Show directions and navigation
- Provide geographic context

## Basic Usage

<Tabs>
  <TabItem value="preview" label="Preview" default>
    <iframe
      src="https://storybook-tx-design.pages.dev/iframe.html?args=&id=tx-design-ui-other-txmap--basic&viewMode=story"
      width="100%"
      height="400px"
      style={{ border: "1px solid #ddd", borderRadius: "8px", background: "white" }}
    />
  </TabItem>
  <TabItem value="code" label="Code">
    ```jsx
    import { TxMap } from "tx-design-ui";

    <TxMap center="New York, NY" zoom={12} height="400px" />
    ```

  </TabItem>
</Tabs>

## API

| Property | Type     | Default | Description          |
| -------- | -------- | ------- | -------------------- |
| center   | `string` | -       | Map location         |
| zoom     | `number` | `10`    | Zoom level           |
| height   | `string` | `400px` | Map height           |
| src      | `string` | -       | Custom iframe source |
