# Code

Inline or block code component.

## When To Use

- Display code snippets
- Show commands
- Highlight technical content

## Basic Usage

<Tabs>
  <TabItem value="preview" label="Preview" default>
    <iframe

  </TabItem>
  <TabItem value="code" label="Code">
    ```jsx
    import { TxCode } from "tx-design-ui";

    <TxCode block={true}>{codeString}</TxCode>
    ```

  </TabItem>

## API

| Property | Type      | Default   | Description     |
| -------- | --------- | --------- | --------------- |
| children | `string`  | -         | Code content    |
| block    | `boolean` | `false`   | Block vs inline |
| variant  | `string`  | `default` | Style variant   |
| size     | `string`  | `14px`    | Font size       |
