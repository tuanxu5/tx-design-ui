# BackTop

Returns to the top of the page.

## When To Use

- When the page content is very long
- When you need to quickly return to the top of the page
- To improve user experience on long pages

## Basic Usage

<Tabs>
  <TabItem value="preview" label="Preview" default>
    <iframe
      src="https://storybook-tx-design.pages.dev/iframe.html?viewMode=story&id=tx-design-ui-other-txbacktop--basic"
      width="100%"
      height="400px"
      style={{border: '1px solid #ddd', borderRadius: '8px', background: 'white'}}
    />
  </TabItem>
  <TabItem value="code" label="Code">
    ```jsx
    import { TxBackTop } from "tx-design-ui";

    <TxBackTop visibilityHeight={400} />
    ```

  </TabItem>
</Tabs>

## API

| Property         | Type               | Default | Description                         |
| ---------------- | ------------------ | ------- | ----------------------------------- |
| visibilityHeight | `number`           | `400`   | Height from bottom before appearing |
| right            | `string \| number` | `48`    | Right offset                        |
| bottom           | `string \| number` | `48`    | Bottom offset                       |
| onClick          | `() => void`       | -       | Click callback                      |
