# Editor

Text editor component for rich content editing.

## When To Use

- Create rich text content
- Text editing interfaces
- Markdown editing

## Basic Usage

    import { TxEditor } from "tx-design-ui";
    import { useState } from "react";

    function MyEditor() {

      return <TxEditor value={value} onChange={setValue} />;
    }

## API

| Property    | Type       | Default | Description      |
| ----------- | ---------- | ------- | ---------------- |
| value       | `string`   | `""`    | Editor value     |
| onChange    | `function` | -       | Change callback  |
| placeholder | `string`   | -       | Placeholder text |
