# Scroll Shadow

Shows shadow effects at scroll boundaries.

## When To Use

- Long scrollable content
- Indicate scroll direction
- Visual scroll feedback

## Basic Usage

<Tabs>
  <TabItem value="preview" label="Preview" default>
    <iframe
      src="https://storybook-tx-design.pages.dev/iframe.html?args=&id=tx-design-ui-other-txscrollshadow--default&viewMode=story"
      width="100%"
      height="400px"
      style={{ border: "1px solid #ddd", borderRadius: "8px", background: "white" }}
    />
  </TabItem>
  <TabItem value="code" label="Code">
    ```jsx
    import { TxScrollShadow } from "tx-design-ui";

    <TxScrollShadow height="300px">
      {content}
    </TxScrollShadow>
    ```

  </TabItem>
</Tabs>

## API

| Property | Type     | Default | Description        |
| -------- | -------- | ------- | ------------------ |
| height   | `string` | `300px` | Container height   |
| children | `node`   | -       | Scrollable content |
