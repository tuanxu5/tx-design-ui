# Scroll Progress

Shows scroll progress indicator for long content.

## When To Use

- Long pages with extensive content
- Progress tracking
- Visual feedback on scroll position

## Basic Usage

<Tabs>
  <TabItem value="preview" label="Preview" default>

## API

| Property | Type      | Default | Description              |
| -------- | --------- | ------- | ------------------------ |
| fixed    | `boolean` | `true`  | Fixed or sticky position |
| top      | `string`  | `0`     | Top offset               |
| height   | `string`  | `4px`   | Progress bar height      |
