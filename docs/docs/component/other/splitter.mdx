# Splitter

Resizable split panes for layout management.

## When To Use

- Create resizable layouts
- Split content into panels
- Provide flexible UI layouts

## API

| Property  | Type     | Default      | Description      |
| --------- | -------- | ------------ | ---------------- |
| direction | `string` | `horizontal` | Split direction  |
| width     | `string` | `100%`       | Container width  |
| height    | `string` | `400px`      | Container height |
| children  | `node`   | -            | Panel contents   |
