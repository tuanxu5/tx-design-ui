# Video Player

Custom video player component.

## When To Use

- Video playback
- Media galleries
- Tutorial content

## API

| Property | Type      | Default | Description     |
| -------- | --------- | ------- | --------------- |
| src      | `string`  | -       | Video URL       |
| poster   | `string`  | -       | Thumbnail image |
| controls | `boolean` | `true`  | Show controls   |
| autoplay | `boolean` | `false` | Autoplay video  |
