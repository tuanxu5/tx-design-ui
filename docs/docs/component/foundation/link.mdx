# Link

Link component with various styles.

## When To Use

- Navigation links
- External references
- Call-to-action buttons

## API

| Property  | Type      | Default | Description        |
| --------- | --------- | ------- | ------------------ |
| href      | `string`  | -       | Link URL           |
| children  | `node`    | -       | Link content       |
| underline | `boolean` | `false` | Show underline     |
| visited   | `boolean` | `false` | Visited link style |
