# Layout

Handles the overall layout of a page.

## When To Use

- Standard page layouts for admin dashboards and web applications
- When you need a consistent layout structure across pages
- For creating page frames with header, sidebar, content, and footer

## API

### TxLayout

| Property  | Type               | Default | Description                |
| --------- | ------------------ | ------- | -------------------------- |
| height    | `string \| number` | `100vh` | Height of layout           |
| minHeight | `string \| number` | `100vh` | Minimum height             |
| flex      | `boolean`          | `false` | Whether to use flex layout |

### TxLayout.Header

Header component at the top of the layout.

### TxLayout.Sider

| Property | Type               | Default | Description      |
| -------- | ------------------ | ------- | ---------------- |
| width    | `string \| number` | `200px` | Width of sidebar |

### TxLayout.Content

Main content area of the layout.

### TxLayout.Footer

Footer component at the bottom of the layout.
