# Drag & Drop

File upload with drag and drop functionality.

## When To Use

- Upload multiple files
- Drag and drop interface
- File browsing

## Basic Usage

<Tabs>
  <TabItem value="preview" label="Preview" default>
    <iframe
      src="https://storybook-tx-design.pages.dev/iframe.html?args=&id=tx-design-ui-other-txdnd--interactive&viewMode=story"

    />
  </TabItem>
  <TabItem value="code" label="Code">
    ```jsx
    import { TxDnd } from "tx-design-ui";

    function MyComponent() {
      const handleDrop = (files) => {
        console.log("Dropped files:", files);
      };

      return (
        <TxDnd onDrop={handleDrop}>
          Drop files here or click to browse
        </TxDnd>
      );
    }
    ```

  </TabItem>
</Tabs>

## API

| Property | Type       | Default | Description           |
| -------- | ---------- | ------- | --------------------- |
| onDrop   | `function` | -       | Handle dropped files  |
| compact  | `boolean`  | `false` | Compact mode          |
| children | `node`     | -       | Custom drop zone text |
