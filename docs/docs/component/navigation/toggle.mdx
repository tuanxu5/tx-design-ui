# Toggle

Simple toggle switch component.

## When To Use

- On/Off settings
- Binary choices
- Feature flags

## API

| Property | Type       | Default  | Description     |
| -------- | ---------- | -------- | --------------- |
| checked  | `boolean`  | `false`  | Initial state   |
| onChange | `function` | -        | Change callback |
| size     | `string`   | `medium` | Size variant    |
| disabled | `boolean`  | `false`  | Disable toggle  |
