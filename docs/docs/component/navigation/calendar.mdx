# Calendar

Calendar component for date selection.

## When To Use

- Date selection
- Event scheduling
- Date range picking

## Basic Usage

  <TabItem value="preview" label="Preview" default>

## API

| Property | Type       | Default | Description     |
| -------- | ---------- | ------- | --------------- |
| value    | `Date`     | -       | Selected date   |
| onChange | `function` | -       | Change callback |
