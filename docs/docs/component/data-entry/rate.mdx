# Rate

Star rating component for user feedback.

## When To Use

- Collect user ratings and reviews
- Show product ratings
- Display satisfaction scores

## Basic Usage

<Tabs>
  <TabItem value="preview" label="Preview" default>

  <TabItem value="code" label="Code">

## API

| Property | Type       | Default | Description         |
| -------- | ---------- | ------- | ------------------- |
| value    | `number`   | `0`     | Current rating      |
| count    | `number`   | `5`     | Total stars         |
| onChange | `function` | -       | Change callback     |
| size     | `string`   | `20px`  | Star size           |
| disabled | `boolean`  | `false` | Disable interaction |
