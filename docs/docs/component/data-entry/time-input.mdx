# Time Input

Time selection input component.

## When To Use

- Time selection
- Scheduling interfaces
- Duration inputs

## API

| Property | Type       | Default | Description     |
| -------- | ---------- | ------- | --------------- |
| value    | `string`   | -       | Time value      |
| onChange | `function` | -       | Change callback |
| disabled | `boolean`  | `false` | Disable input   |
