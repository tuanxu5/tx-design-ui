# Input OTP

One-time password input component.

## When To Use

- Two-factor authentication
- Verification codes
- PIN entry

## API

| Property | Type       | Default | Description          |
| -------- | ---------- | ------- | -------------------- |
| length   | `number`   | `6`     | Number of OTP digits |
| onChange | `function` | -       | Change callback      |
| disabled | `boolean`  | `false` | Disable input        |
