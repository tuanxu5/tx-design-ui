# Chart

Data visualization component (integrate with Chart.js or similar).

## When To Use

- Display data trends
- Show statistics and metrics
- Visualize complex data sets

## API

| Property | Type     | Default | Description   |
| -------- | -------- | ------- | ------------- |
| type     | `string` | `bar`   | Chart type    |
| data     | `object` | -       | Chart data    |
| options  | `object` | -       | Chart options |
