# Divider

Horizontal or vertical divider component.

## When To Use

- Separate content sections
- Create visual hierarchy
- Group related items

## API

| Property  | Type      | Default | Description      |
| --------- | --------- | ------- | ---------------- |
| vertical  | `boolean` | `false` | Vertical divider |
| thickness | `string`  | `1px`   | Line thickness   |
| margin    | `string`  | `16px`  | Margin spacing   |
