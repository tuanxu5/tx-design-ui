# Skeleton

Loading skeleton component with shimmer effect.

## When To Use

- Show loading states
- Placeholder during data fetch
- Improve perceived performance

## Basic Usage

<Tabs>
  <TabItem value="preview" label="Preview" default>
    <iframe
      src="https://storybook-tx-design.pages.dev/iframe.html?args=&id=tx-design-ui-other-txskeleton--basic&viewMode=story"
      width="100%"
      height="200px"
      style={{ border: "1px solid #ddd", borderRadius: "8px", background: "white" }}
    />
  </TabItem>
  <TabItem value="code" label="Code">

## API

| Property | Type     | Default | Description           |
| -------- | -------- | ------- | --------------------- |
| width    | `string` | `100%`  | Skeleton width        |
| height   | `string` | `20px`  | Skeleton height       |
| variant  | `string` | `rect`  | Variant (rect/circle) |
| radius   | `string` | `4px`   | Border radius         |
