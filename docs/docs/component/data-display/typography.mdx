# Typography

Typography component with various text styles.

## When To Use

- Display headings and titles
- Style body text
- Show captions and labels

## API

| Property | Type      | Default | Description                         |
| -------- | --------- | ------- | ----------------------------------- |
| variant  | `string`  | -       | Text variant (h1-h4, body, caption) |
| color    | `string`  | -       | Text color                          |
| size     | `string`  | -       | Font size                           |
| weight   | `string`  | -       | Font weight                         |
| align    | `string`  | `left`  | Text alignment                      |
| ellipsis | `boolean` | `false` | Truncate with ellipsis              |
