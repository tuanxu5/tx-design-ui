# Image

Enhanced image component with loading and error states.

## When To Use

- Display images with loading states
- Handle image errors gracefully
- Add zoom effects on hover

## Basic Usage

## API

| Property    | Type      | Default | Description            |
| ----------- | --------- | ------- | ---------------------- |
| src         | `string`  | -       | Image source           |
| alt         | `string`  | -       | Alt text               |
| width       | `string`  | `100%`  | Image width            |
| height      | `string`  | `auto`  | Image height           |
| zoom        | `boolean` | `false` | Enable zoom on hover   |
| objectFit   | `string`  | `cover` | Object fit style       |
| placeholder | `string`  | -       | Error placeholder text |
