# Alert

Alerts display important messages to users.

## When To Use

- To display important information that requires immediate attention
- To provide feedback to users about their actions
- To communicate errors, warnings, or success messages
- When you need to convey critical information prominently

## API

| Property    | Type                                          | Default  | Description                   |
| ----------- | --------------------------------------------- | -------- | ----------------------------- |
| type        | `'success' \| 'info' \| 'warning' \| 'error'` | `'info'` | Type of alert                 |
| title       | `string`                                      | -        | The title of the alert        |
| description | `string`                                      | -        | The description of the alert  |
| closable    | `boolean`                                     | `false`  | Whether to show close button  |
| onClose     | `() => void`                                  | -        | Callback when alert is closed |
| children    | `ReactNode`                                   | -        | Custom content                |
