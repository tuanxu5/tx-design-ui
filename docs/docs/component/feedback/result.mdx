# Result

Used to feed back the result of a series of operation tasks.

## When To Use

- Used to display the result of operations such as submission, checkout, and payment
- Display important tips when there are exceptions and failures
- Use illustrations to enhance the visual effect

## Basic Usage

## API

| Property | Type                                          | Default  | Description       |
| -------- | --------------------------------------------- | -------- | ----------------- |
| status   | `'success' \| 'error' \| 'warning' \| 'info'` | `'info'` | Result status     |
| icon     | `ReactNode`                                   | -        | Custom icon       |
| title    | `ReactNode`                                   | -        | Title             |
| subTitle | `ReactNode`                                   | -        | Subtitle          |
| extra    | `ReactNode`                                   | -        | Extra action area |
| children | `ReactNode`                                   | -        | Custom content    |
